# Bài 6 : Ngăn chặn rò rỉ thông tin bí mật trên GitHub

## Một repository mẫu trên GitHub chứa cấu trúc file an toàn và bản báo cáo đánh giá rủi ro nếu thiếu tệp .gitignore.

- **Trả lời:** 
   + Cấu trúc repo : ecommerce-demo/.gitignore , ecommerce-demo/.env.example , ecommerce-demo/SECURITY.md , ecommerce-demo/RISK_REPORT.md
   + Trong file .gitignore gõ : 
```
.env
.env.*
!.env.example
*.pem
*.key
node_modules/
*.log
```
   + Trong .env.example gõ :
```
APP_ENV=development   # development | test | production
DB_USER=your_db_user
DB_PASSWORD=your_db_password
PAYMENT_API_KEY=your_api_key
```
  + Rủi ro khi thiếu .gitignore : mất dữ liệu khách hàng , gian lận tài chính , bị chiếm quyền server , lộ thông tin nội bộ ,...
